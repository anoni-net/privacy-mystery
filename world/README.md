# 霧港設定集

這份是隱私推理遊戲的世界觀設定，給寫新案件、改舊案件的人對照用，讓各案的人物、公司、網站與時間前後一致。這裡只放已經公開的設定，**不寫任何案件的解答或兇手**，解答只存在各案加密的 `solution.enc` 裡。

## 系列的形式

同一個世界，各案獨立。每一案有自己的委託人、手法與結局，玩家從任何一案開始都看得懂，不必照編號玩。案件之間可以有呼應，例如前一案的公司在下一案又出現，但不寫成需要先玩前一案才懂的劇情。

各案自己標日期，時間可以前後跳，大廳照編號排列。

## 世界

時間是 2026 年起的台灣，地點用真實的城市與行政區（台北市內湖區、新北市三重區），公司、人物、網站與事件都是虛構的。遊戲裡的網路世界有自己的搜尋引擎、論壇與社群平台，取代真實世界的服務，避免冒用真實品牌。

### 霧港隱私互助站

玩家所在的組織，英文是 Mistport Privacy Aid。一群志工替遇到隱私問題的人提供協助：被爆料後怕身分曝光、被詐騙、帳號被接走、資料外洩。委託人透過端對端加密的通訊找來，也有 165 反詐騙專線轉介過來的。

玩家坐在「霧港工作站 03」前面，桌面上有加密通訊、瀏覽器、檔案、看圖、終端機、調查板與結案報告。互助站的名字取自「起霧的港口」，代表在看不清楚的地方提供一個可以停靠的地方。

## 案件的共同結構

1. 開場是和委託人的加密對話，選幾次回覆，收下委託人整理的資料
2. 調查時，找到的線索會自動記錄在調查板，玩家也可以把網頁、表格、紀錄釘選上去
3. 每一案有一個陷阱，看起來是自然的下一步，做了卻會傷到委託人。落入陷阱會降一級評等，阿霧會說明原因
4. 用證據把嫌疑人一個一個排除，縮小匿名集合
5. 結案報告：幾題選擇題，加上指認一個人。指認正確才解得開加密的解答，評等看提示數、誤判次數與陷阱

每一案都有不需要 JavaScript 的靜態版與可列印的 PDF（新案件可以先上線互動版），中英文各一份。

## 虛構資料的寫法

- IP 位址只用文件專用的範圍：`203.0.113.0/24`、`198.51.100.0/24`、`192.0.2.0/24`
- 網域用遊戲裡的品牌（`beatbird.app`）、`.mist` 或 `.example`，不用真實存在的公司網域
- 電話、統一編號、會員編號都是編的。QR code 的內容用虛構的 App 指令（例如 `ripple://`），掃了不會開啟任何網站
- 取材自真實事件或真實信件時只取手法，不放原文、真名、真實網址或電話

## 寫作與安全

- 文字照 anoni.net 的[寫作風格規範](https://anoni.net/join/writing-style/)
- 教的是辨識與保護，不寫可以直接拿去濫用的操作步驟
- 不冒用真實的公司與品牌，不針對真實人物
- 不讓兇手的名字出現在 commit、PR、issue 與這份設定集裡
